## Folio 0.1.0 — первая версия

Читалка документов для Windows в одном окне с вкладками.

- **Форматы:** PDF (pdfium), DOCX, ODT, RTF, EPUB, FB2, Markdown, HTML, TXT, XLSX/XLS/ODS/CSV, PPTX/ODP, JSON, XML, исходный код, картинки, комиксы CBZ.
- **Чтение:** четыре темы (Mocha, светлая, сепия, чёрная), шрифты с засечками и без, ширина колонки; тёмные страницы PDF в тёмных темах; запоминание места и масштаба; поиск с подсветкой; оглавление, миниатюры, закладки; чтение вслух голосом Windows.
- **Удобства:** палитра команд `Ctrl+K`, следующий/предыдущий файл в папке, сохранение текста в `.txt` и страницы в PNG, одно окно на пользователя.
- **Windows:** установщик без прав администратора, «Открыть с помощью» и «Приложения по умолчанию», пункт в меню правой кнопки (по желанию), автообновление с проверкой SHA-256.
- **Командная строка:** `folio-cli text | info | formats`.

Проверено тестами (81), изолированной веткой реестра и отрисовкой окна за экраном. Не проверялось вживую: озвучка (звук), несколько мониторов и масштаб выше 100 %, меню Проводника на реальной системе, обновление с настоящего релиза, печать. Не поддерживаются `.doc`, `.ppt`, DjVu, CBR.

**Файлы релиза:** `Folio-Setup.exe`, `Folio.exe`, `folio-cli.exe`, `SHA256SUMS.txt`. Исполняемые файлы не подписаны (SmartScreen); телеметрии нет, единственный сетевой запрос — проверка новой версии (отключается в настройках).
