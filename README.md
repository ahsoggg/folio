# Folio

[English](README.en.md) · [Русский](README.md)

Читалка документов для Windows: PDF, Word, EPUB, FB2, таблицы, презентации, Markdown, код и картинки — в одном окне
с вкладками. Помнит, где вы остановились, ищет по тексту с подсветкой, читает вслух голосом Windows и подстраивается
под глаза: четыре темы (Catppuccin Mocha, светлая, сепия, чёрная), шрифты с засечками и без, ширина колонки, интервал.
Написана на Rust (egui); страницы PDF рисует pdfium — движок Chrome.

![Документ Word: оглавление слева, текст с оформлением](docs/screenshots/02-docx.png)

*Все скриншоты сделаны на выдуманных документах (`Folio.exe --screenshots`) — настоящих файлов на них нет.*

## Возможности (версия 0.1.0)

- **Форматы.** PDF (страницы как в оригинале, выделение и копирование текста, ссылки, оглавление, пароли), DOCX/DOCM,
  ODT, RTF, EPUB, FB2 (в том числе `.fb2.zip`, любые кодировки), Markdown, HTML, TXT (кодировка определяется сама:
  UTF-8/16, Windows-1251, CP866), XLSX/XLS/XLSB/ODS и CSV/TSV (сетка с буквами столбцов), PPTX и ODP (слайды как
  разделы, заметки докладчика), JSON, XML, исходный код с подсветкой синтаксиса, картинки и комиксы CBZ.
  Старые двоичные `.doc` и `.ppt`, DjVu и CBR не поддерживаются — их надо сначала пересохранить.
- **Читать удобно.** Текст в колонке нужной ширины, настоящий жирный и курсив, таблицы, списки, картинки, цитаты,
  ссылки (с подтверждением перед открытием в браузере). Размер шрифта, интервал, выравнивание по ширине.
  Цвета из документа заменяются на цвет темы, если их не видно на фоне.
- **Темы и PDF.** В тёмных темах страницы PDF сами становятся тёмными (картинка инвертируется и переводится в цвета
  темы), в сепии — как бумага. Отключается в настройках.
- **Поиск.** `Ctrl+F` — по всему документу с подсветкой всех совпадений, переходом `F3` / `Shift+F3` и списком
  результатов в боковой панели; в PDF — с учётом регистра, в таблицах — по ячейкам.
- **Навигация.** Вкладки, оглавление (из заголовков, закладок PDF, NCX/nav EPUB), миниатюры страниц, переход к
  странице `Ctrl+G`, закладки `Ctrl+B`, следующий/предыдущий файл в папке `Alt+→` / `Alt+←` (удобно для книг и
  комиксов), индикатор прочитанного и «осталось ≈ 12 мин».
- **Помнит место.** Закройте книгу — завтра она откроется на том же абзаце, с тем же масштабом. При смене размера
  шрифта читаемое место сохраняется. Недавние файлы со шкалой прочитанного на стартовом экране.
- **Читает вслух.** `Ctrl+L` — голос Windows (SAPI; русский выбирается сам, если установлен) читает абзац за абзацем
  с подсветкой и автопрокруткой; пауза, скорость в настройках.
- **Палитра команд.** `Ctrl+K` — поиск по командам, вкладкам и недавним файлам. `T` — смена темы, `F11` — весь экран.
- **Сохранить.** Весь текст — в буфер или в `.txt`; страницу PDF или комикса — в PNG; печать через программу печати
  Windows.
- **Интеграция с Windows.** «Открыть с помощью» и «Приложения по умолчанию» (Windows не даёт программам назначать
  себя за пользователя — выбор делаете вы), пункт «Читать в Folio» в меню правой кнопки (по желанию), одно окно на
  пользователя: файл, открытый из Проводника, появляется в уже запущенном Folio. Перетаскивание файлов в окно.
- **Установка и обновление.** `Folio-Setup.exe` ставит программу в `%LOCALAPPDATA%\Programs\Folio` без прав
  администратора. Раз в сутки один запрос к `api.github.com`; кнопка «Обновить», проверка SHA-256 по
  `SHA256SUMS.txt`, замена файла и перезапуск; `Folio.exe --update` — то же без окна.
- **Командная строка.** `folio-cli text файл` — текст любого поддерживаемого документа, `folio-cli info`, `formats`.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+O` | открыть файл (можно перетащить в окно) |
| `Ctrl+K` | палитра команд |
| `Ctrl+F`, `F3`, `Shift+F3` | поиск, следующее, предыдущее |
| `Ctrl+G` | перейти к странице / проценту / строке |
| `Ctrl+B` | закладка |
| `Ctrl+L` | читать вслух |
| `Ctrl +`, `Ctrl −`, `Ctrl+0`, `Ctrl`+колесо | масштаб PDF или размер шрифта |
| `Пробел`, `PgDn`, `PgUp`, `↑`, `↓`, `J`, `K`, `Home`, `End` | прокрутка; `←` `→` — страницы PDF |
| `Alt+→`, `Alt+←` | следующий / предыдущий файл в папке |
| `Ctrl+Tab`, `Alt+1…9`, `Ctrl+W` | вкладки |
| `T`, `F11`, `Ctrl+,` | тема, весь экран, настройки |
| `Ctrl+P` | печать |

## Установка

Скачайте `Folio-Setup.exe` со страницы [Releases](https://github.com/ahsoggg/folio/releases/latest) и
запустите. Права администратора не нужны: программа ставится в `%LOCALAPPDATA%\Programs\Folio`, в меню «Пуск»
появляется ярлык, в «Приложения и возможности» — запись для удаления, а в «Открыть с помощью» — Folio. Есть и
переносная версия — просто `Folio.exe` (установить её можно позже из «Настроек»); `folio-cli.exe` — консольная.

Исполняемые файлы **не подписаны**: SmartScreen может показать «неизвестный издатель» («Подробнее» → «Выполнить в
любом случае»). Что файл совпадает с опубликованным, видно по `SHA256SUMS.txt` из того же релиза.

## Приватность

Folio ничего никуда не отправляет, кроме проверки обновлений на GitHub (раз в сутки, отключается в настройках).
Телеметрии нет, документы не покидают компьютер. Локально хранятся: настройки и история чтения
(`%APPDATA%\Folio\settings.json`, `library.json`), журнал и отчёты о сбоях (`%APPDATA%\Folio\logs`, профиль
пользователя в них заменяется на `%USERPROFILE%`), распакованная библиотека pdfium (`%LOCALAPPDATA%\Folio`).
«Очистить историю чтения» в настройках стирает `library.json`.

## Сборка

```powershell
cargo test --workspace            # 81 тест, в том числе настоящий pdfium
cargo build --release             # target\release\Folio.exe и folio-cli.exe
target\release\Folio.exe --screenshots docs\screenshots   # перерисовать скриншоты (окно вне экрана)
powershell -ExecutionPolicy Bypass -File scripts\release.ps1   # проверки + dist\ с контрольными суммами
```

Устройство: `crates/core` — чтение форматов в одну модель документа (блоки, стили, таблицы, картинки) и PDF-движок
(pdfium в отдельном потоке); `crates/app` — окно на egui, настройки, история, установщик, обновление, интеграция с
Проводником, озвучка; `crates/cli` — консольный `folio-cli`. pdfium (`assets/pdfium/pdfium.dll`, зафиксирован по
SHA-256) встроен в `Folio.exe` и распаковывается при первом открытии PDF — поэтому установка и обновление остаются
заменой одного файла.

Релиз: поднять версию в `Cargo.toml`, обновить `docs/RELEASE_NOTES.md`, `git tag vX.Y.Z && git push --tags` — GitHub
Actions соберёт, проверит и опубликует файлы.

## Что не проверялось и ограничения

Проверено тестами (81), изолированной веткой реестра и отрисовкой окна за экраном. **Не проверялось вживую:** озвучка
(звук), работа на нескольких мониторах и при масштабе экрана выше 100 %, меню Проводника и «Открыть с помощью» на
реальной системе, обновление с настоящего релиза, печать. Не поддерживается: `.doc`, `.ppt`, DjVu, CBR/RAR, режим
двух страниц, редактирование и аннотации. Сноски DOCX и формулы не показываются.
